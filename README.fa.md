# مهردادیکا

**انگلیسی را با تصویر، خواندن و موضوع‌های روزمره یاد بگیرید؛ با راهنمایی به زبان خودتان.**

مهردادیکا یک وب‌اپ رایگان و متن‌باز برای یادگیری انگلیسی است؛ با راهنمای فارسی، پرتغالی برزیلی و اسپانیایی آمریکای لاتین. واژه‌ها را با تصویر کشف کنید، عادت مطالعهٔ روزانه بسازید و با داستان و علوم انگلیسی تمرین کنید. در همهٔ نسخه‌ها، زبانِ یادگیری انگلیسی است و توضیح‌ها و دستور تمرین‌ها به زبان انتخابی شما ارائه می‌شوند.

[امتحان برنامه](https://mehrdadxzaker.github.io/mehrdadika/) · [مشارکت](#مشارکت) · [گزارش مشکل](https://github.com/mehrdadxzaker/mehrdadika/issues/new/choose)

## تازه‌ترین تغییرات

**۳۰ اکتبر ۲۰۲۶ · پیش‌نمایش توسعه**

- **تازه‌ترین گسترش واژگان:** ۲۴ مدخل تصویری تازه شامل ۱۲ واژهٔ پزشکی و ۱۲ واژهٔ مهندسی افزوده شده است. [جزئیات این مرحله](docs/specialist-expansion-34-ready-1.md).
- **علوم به زبان انگلیسی:** دورهٔ _Water and Weather_ شامل هشت درس تصویری، ۳۲ تمرین، هشت فعالیت نوشتاری و ۱۹ واژهٔ علمی تازه است و راهنمای فارسی، پرتغالی و اسپانیایی دارد.
- **سه نسخه در یک برنامه:** مطالعهٔ روزانه، مرور فاصله‌دار، خواندن، تمرین، تنظیمات و پشتیبان‌گیری در هر سه زبان از همان برنامه استفاده می‌کنند؛ پیشرفت هر نسخه جداست.
- **اطلس تصویری در حال گسترش:** مجموعهٔ فعلی ۱۰۴۱ واژه و ۱۰۴۲ معنی دارد. هر ۳۲ دسته مدخل‌های تصویری آغازین دارند؛ آشپزی شامل ۵۲ واژه و پزشکی و مهندسی به‌ترتیب شامل ۴۴۲ و ۴۴۱ واژه‌اند. در مرحلهٔ پیشینِ پایه‌های بصری، به هر دسته دو مدخل با سبک تصویری متناسب با همان موضوع افزوده شد.

محتوا و ترجمه‌ها **پیش‌نمایش ویرایشی با کمک هوش مصنوعی** هستند و هنوز به بازبینی مستقل انسانی نیاز دارند. مطالب تخصصی باید به دست افراد آشنا با همان رشته نیز بررسی شوند. این فهرست وضعیت فعلی کد و محتوا را توصیف می‌کند؛ وب‌سایت بر اساس آخرین انتشار دستی به‌روز می‌شود. جزئیات در [وضعیت پیاده‌سازی](docs/implementation-status.md) و [گزارش بررسی‌ها](docs/verification.md) آمده است.

## با مهردادیکا چه کارهایی می‌توانید انجام دهید؟

| بخش یادگیری             | امکانات                                                                                                                                                                                        |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| مطالعهٔ روزانه          | هدف روزانه تعیین کنید، واژه‌ها را در دسته‌های کوچک یاد بگیرید، یادآوری فعال تمرین کنید و با زمان‌بندی مرور فاصله‌دار FSRS مرور کنید.                                                           |
| اطلس تصویری             | کارت واژه‌ها را با معنی، مثال، ترکیب‌های رایج و تلفظ ببینید؛ جست‌وجو و فیلتر کنید، واژه ذخیره کنید و پیشرفتتان را در کهکشان واژگان دنبال کنید.                                                 |
| خواندن                  | سه متن کوتاه و یک کتاب تألیفی سه‌فصلی را با ترجمه، پرسش‌های درک مطلب، نشان‌گذاری و جست‌وجوی واژه در متن بخوانید.                                                                               |
| تمرین                   | نوشتن واژه، رونویسی جمله، دیکته، دو سطح بازنویسی و سه گروه واژه‌های اشتباه‌پذیر را تمرین کنید.                                                                                                 |
| علوم به زبان انگلیسی    | در دورهٔ مقدماتی _Water and Weather_ مشاهده‌ها را توصیف کنید، ایده‌ها را مقایسه کنید و علت‌ها را توضیح دهید. سطح هدف تقریباً A2 تا ابتدای B1 است. دوره را در **کتابخانه ← دوره‌ها** پیدا کنید. |
| پیشرفت و مطالعهٔ آفلاین | پیشرفت را روی دستگاه نگه دارید، پشتیبان بگیرید یا بازیابی کنید و از نسخهٔ ساخته‌شدهٔ برنامه، بستهٔ مطالعهٔ آفلاین دریافت کنید.                                                                 |

نقشهٔ محتوا **۳۲ خانوادهٔ موضوعی و ۳۴۸ زیردسته** دارد؛ از زندگی روزمره و آشپزی تا فناوری و سلامت. این نقشه محدودهٔ پوشش را نشان می‌دهد و بسیاری از بخش‌ها هنوز به درس نیاز دارند. پایان درس علوم، مشارکت در دوره را جدا از تسلط بر واژگان انگلیسی ثبت می‌کند؛ فعالیت‌های نوشتاری با ذخیرهٔ پیش‌نویس و خودبازبینی همراه‌اند.

### پیشرفت شما و دستگاهتان

پیشرفت، واژه‌های ذخیره‌شده، نشست‌های فعال و وضعیت خواندن و دوره‌ها در مرورگر همین دستگاه نگهداری می‌شوند و برای هر نسخهٔ زبانی جدا هستند. سرویس حساب کاربری یا همگام‌سازی خودکار میان دستگاه‌ها وجود ندارد. پیش از جابه‌جایی دستگاه یا پاک‌کردن داده‌های مرورگر، پشتیبان بگیرید.

بسته‌های آفلاین به نسخهٔ ساخته‌شدهٔ برنامه و فضای کافی در مرورگر نیاز دارند. خواندن متن‌ها و تلفظ واژه‌های بدون فایل ضبط‌شده از صدای انگلیسی دستگاه استفاده می‌کند و به مرورگر و سیستم‌عامل بستگی دارد. ابزارهای پولی تولید محتوا فقط امکانات اختیاری برای نگهدارندگان پروژه‌اند.

## مشارکت

**بدون برنامه‌نویسی هم می‌توانید کمک کنید.** از معلم‌ها، زبان‌آموزها، مترجم‌ها، تصویرگرها، بازبین‌های تخصصی و توسعه‌دهنده‌ها استقبال می‌کنیم.

| علاقهٔ شما              | یک مشارکت کوچک برای شروع                                                                                                      |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| زبان و آموزش            | پنج توضیح یا مثال از یک درس را بررسی کنید و پیشنهادهایی برای فارسی، پرتغالی برزیلی یا اسپانیایی آمریکای لاتینِ روان‌تر بدهید. |
| یادگیری و آزمایش        | یک درس را روی گوشی امتحان کنید و بخش گیج‌کننده، مشکل چیدمان یا مانع دسترس‌پذیری را گزارش دهید.                                |
| تصویر و موضوع‌های تخصصی | بررسی کنید که آیا تصویر، معنی مورد نظر را می‌رساند یا یک بخش کوچک از محتوای تخصصی را بازبینی کنید.                            |
| توسعه و مستندات         | یک رفتار مشخص رابط را بهتر کنید، خطایی قابل بازتولید را برطرف کنید یا راهنمای راه‌اندازی را روشن‌تر بنویسید.                  |

1. برای اصلاح یا پیشنهادتان [یک ایشو باز کنید](https://github.com/mehrdadxzaker/mehrdadika/issues/new/choose). نام واژه یا درس، متن فعلی، متن پیشنهادی و دلیل تغییر را بنویسید. اگر شناسهٔ محتوا، شمارهٔ بازبینی و مرجع را دارید، اضافه کنید؛ در غیر این صورت صفحه را توصیف کنید و برای پیدا کردنشان کمک بخواهید. فارسی، پرتغالی، اسپانیایی و انگلیسی پذیرفته‌اند.
2. برای تغییر کد یا محتوا، [راهنمای مشارکت](CONTRIBUTING.md) و [راهنمای محتوا](docs/contributing-content.md) را بخوانید و درخواست ادغام را کوچک و قابل بررسی نگه دارید. راهنماهای تفصیلی مشارکت در حال حاضر انگلیسی هستند.
3. منابع، مجوزها و بازبینی‌های انجام‌شده را دقیق و صادقانه ثبت کنید. بازبینی مستقل زبانی و تخصصی برای رساندن محتوای پیش‌نمایش به انتشار پایدار بسیار ارزشمند است.

[آیین رفتار](CODE_OF_CONDUCT.md) را رعایت کنید. برای مسائل امنیتی، از دستورهای گزارش در [SECURITY.md](SECURITY.md) استفاده کنید.

## اجرای محلی

**پیش‌نیازها:** Node.js نسخهٔ ۲۲ یا جدیدتر، npm و Git. به سرور پایگاه داده یا اطلاعات حساب هوش مصنوعی نیاز ندارید.

<div dir="ltr">

```sh
git clone https://github.com/mehrdadxzaker/mehrdadika.git
cd mehrdadika
npm ci
npm run dev
```

</div>

نشانی چاپ‌شده در ترمینال را باز کنید؛ معمولاً `http://127.0.0.1:5188` است. فرمان توسعه، خروجی‌های محتوا و ترجمه را خودکار می‌سازد. در هر زمان فقط یک سرور توسعه یا پیش‌نمایش اجرا کنید.

### بررسی و ساخت

<div dir="ltr">

```sh
npm test
npm run check:content
npm run campaign:status
npm run build
```

</div>

خروجی نهایی در `dist/` قرار می‌گیرد. پس از توقف سرور توسعه، با `npm run preview` نسخهٔ ساخته‌شده و امکانات آفلاین آن را بررسی کنید.

### ساختار پروژه

| مسیر       | کاربرد                                                     |
| ---------- | ---------------------------------------------------------- |
| `src/`     | برنامهٔ React و TypeScript، روندهای یادگیری و رابط زبان‌ها |
| `content/` | واژگان، متن‌ها، دوره‌ها، ترجمه‌ها و اطلاعات منشأ محتوا     |
| `public/`  | فایل‌های ایستا و نسخه‌های ساخته‌شده و نسخه‌دار محتوا       |
| `scripts/` | ابزارهای ساخت محتوا، اعتبارسنجی و بررسی‌های رگرسیون        |
| `docs/`    | راهنماهای تألیف، برنامه‌ها و گزارش بررسی‌ها                |

منابع تألیف را در `content/` ویرایش کنید و خروجی محتوا و ترجمه‌ها را با ابزارهای مستندشده دوباره بسازید. شناسهٔ واژه‌ها و معنی‌ها را ثابت نگه دارید تا اصلاح محتوا، پیشرفت زبان‌آموز را حفظ کند.

## استقرار

پوشهٔ `dist/` را روی یک میزبان فایل ایستا ارائه کنید. برای GitHub Pages در مسیر مخزن:

<div dir="ltr">

```sh
ATLAS_BASE=/mehrdadika/ npm run build
```

</div>

برای ریشهٔ دامنه از `ATLAS_BASE=/` استفاده کنید. گردش‌کار **Deploy GitHub Pages** در مخزن به‌صورت دستی اجرا می‌شود؛ ارسال تغییرات و درخواست ادغام، سایت را خودکار منتشر نمی‌کند. هنگام به‌روزرسانی، فایل‌های نسخه‌دار محتوا را نگه دارید تا نشست‌های ذخیره‌شده همچنان به نسخهٔ خود دسترسی داشته باشند.
