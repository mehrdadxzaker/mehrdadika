# مهردادیکا

مهردادیکا یک اطلس تصویری و متن‌باز برای یادگیری انگلیسی با توضیح‌های فارسی است. این پروژه با اقتباس از [Word Atlas](https://github.com/designfuchen/word-atlas) ساخته می‌شود و کارت‌های تصویری واژگان، یادگیری روزانه، یادآوری فعال، مرور فاصله‌دار و نمایش پیشرفت در یک آسمان واژگانی را دنبال می‌کند.

## اجرای محلی

به Node.js نسخهٔ ۲۲ یا جدیدتر و npm نیاز دارید. برای مطالعه و مشارکت معمولی، حساب سرویس هوش مصنوعی، کلید API یا سرور پایگاه داده لازم نیست.

```sh
npm ci
npm run dev
```

نشانی محلی چاپ‌شده در ترمینال را باز کنید. در هر زمان تنها یک سرور توسعه اجرا کنید. برای محدود کردن دسترسی سرور به رایانهٔ خود:

```sh
npm run dev -- --host 127.0.0.1
```

نشانی پیش‌فرض `http://127.0.0.1:5188` است. پیش از اجرای سرور، نسخهٔ فعلی محتوا به‌صورت خودکار ساخته می‌شود.

## بررسی و ساخت

```sh
npm test
npm run check:content
npm run build
```

خروجی ساخت در پوشهٔ `dist/` قرار می‌گیرد و می‌توان آن را روی یک میزبان فایل ایستا اجرا کرد. پیشرفت یادگیری در مرورگر نگهداری می‌شود؛ پیش از جابه‌جایی دستگاه یا پاک کردن داده‌های مرورگر، نسخهٔ پشتیبان بگیرید.

برای بررسی محلی نسخهٔ ساخته‌شده، سرور توسعه را متوقف و `npm run preview` را اجرا کنید. هر دو فرمان از درگاه ۵۱۸۸ استفاده می‌کنند و سرور دوم روی درگاه اشغال‌شده اجرا نمی‌شود. دریافت بستهٔ کامل آفلاین مربوط به نسخهٔ ساخته‌شده است و سرور توسعه چنین تضمینی نمی‌دهد.

برای انتشار زیر یک مسیر:

```sh
ATLAS_BASE=/mehrdadika/ npm run build
```

برای ریشهٔ یک دامنه از `ATLAS_BASE=/` استفاده کنید. فایل‌های محتوا و رسانه باید زیر همین مسیر قابل دریافت باشند. نسخه‌های قدیمی محتوا را هنگام انتشار نسخهٔ جدید، تا پایان دورهٔ پشتیبانی حذف نکنید.

گردش‌کار GitHub Pages تنها به‌صورت دستی اجرا می‌شود. در تنظیمات مخزن، Pages را روی GitHub Actions قرار دهید و سپس گردش‌کار **Deploy GitHub Pages** را با مسیر درست اجرا کنید. برای سایت یک مخزن معمولاً مسیر `/REPOSITORY-NAME/` و برای دامنهٔ اختصاصی معمولاً `/` مناسب است. هیچ انتشار خودکاری با ارسال تغییرات یا درخواست ادغام انجام نمی‌شود.

## دسته‌ها و تجربهٔ یادگیری

پنج بخش اصلی برنامه عبارت‌اند از **امروز، اطلس، کتابخانه، تمرین و من**. متن انگلیسی در رابط فارسی همچنان از چپ به راست نمایش داده می‌شود.

فهرست کامل شامل ۳۲ خانوادهٔ موضوعی است که در شش گروه اکتشافی قرار می‌گیرند:

- زندگی روزمره و روابط: زندگی روزمره؛ افراد و روابط؛ خانه، باغبانی و تعمیرات خانگی؛ فرزندپروری و مراقبت از خانواده؛ مد، زیبایی و مراقبت شخصی؛ بهزیستی و عادت‌های روزانه.
- غذا، سفر و اوقات فراغت: آشپزی، غذا و نوشیدنی؛ سفر، گردشگری و هتلداری؛ حمل‌ونقل و وسایل نقلیه؛ ورزش و تفریح؛ جانوران، حیوانات خانگی و حیات وحش؛ بازی‌های رایانه‌ای و فرهنگ دیجیتال.
- یادگیری، علم و ارتباطات: آموزش و انگلیسی دانشگاهی؛ علوم طبیعی و ریاضیات؛ زبان‌ها و ارتباطات؛ جغرافیا، مکان‌ها و فرهنگ‌ها.
- سلامت، جامعه و فرهنگ: پزشکی و سلامت؛ حقوق و امور عمومی؛ علوم انسانی و جامعه؛ هنر و رسانه؛ ایمنی و وضعیت‌های اضطراری.
- فناوری، صنعت و محیط زیست: مهندسی؛ رایانش و فناوری؛ معماری و زیرساخت؛ محیط زیست و کشاورزی؛ حرفه‌ها و کارهای فنی؛ تولید، لجستیک و زنجیرهٔ تأمین؛ انرژی، آب و منابع طبیعی.
- کسب‌وکار و زندگی شغلی: کسب‌وکار و مدیریت؛ اقتصاد و امور مالی؛ خرده‌فروشی و تجارت الکترونیک؛ مسیر شغلی و محیط کار.

وجود یک دسته به معنی آماده بودن همهٔ درس‌های آن نیست. مطالب منتشرشده، مطالب آینده و پیش‌نویس‌ها وضعیت‌های جداگانه دارند. هر واژه می‌تواند در چند دسته دیده شود، اما سابقهٔ یادگیری آن تکثیر نمی‌شود. معنی‌های متفاوت یک واژه، سابقهٔ مرور مستقل دارند.

## انتشار تدریجی محتوا

واژگان، متن‌ها، کتاب‌ها و تمرین‌ها در بسته‌های موضوعی نسخه‌دار منتشر می‌شوند. شناسهٔ مطالب ثابت می‌ماند تا انتشار مطالب جدید، پیشرفت یادگیری را از بین نبرد.

محتوای آغازین، **پیش‌نمایش ویرایشی با کمک هوش مصنوعی** است. این وضعیت نباید به‌عنوان تأیید مستقل انسانی یا تأیید متخصص پزشکی و مهندسی معرفی شود. انتشار پایدار به ثبت بازبینی زبانی انسانی و برای مطالب تخصصی به بازبینی فرد آشنا با آن رشته نیاز دارد. پیش‌نویس‌ها وارد نسخهٔ قابل مطالعه نمی‌شوند، حتی اگر نسخه در کانال پیش‌نمایش باشد.

برای پیشنهاد ترجمه، اصلاح واژه، افزودن تصویر، تلفظ، موضوع یا کد، [راهنمای مشارکت در محتوا](docs/contributing-content.md) را بخوانید. استفاده از ابزارهای پولی تولید محتوا اختیاری است.
