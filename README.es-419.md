# Mehrdadika · مهردادیکا

**Aprende inglés con imágenes, lecturas y temas cotidianos, con orientación en tu idioma.**

Mehrdadika es una aplicación web gratuita y de código abierto para aprender inglés, dirigida a hablantes de persa, portugués brasileño y español latinoamericano. Explora palabras ilustradas, crea un hábito de estudio diario y practica inglés con historias y ciencias. Todas las ediciones enseñan inglés; las explicaciones e instrucciones te acompañan en el idioma que elijas.

[Prueba la aplicación](https://mehrdadxzaker.github.io/mehrdadika/#/es-419) · [Cómo contribuir](#cómo-contribuir) · [Reporta un problema](https://github.com/mehrdadxzaker/mehrdadika/issues/new/choose)

## Cambios recientes

**27 de octubre de 2026 · Versión preliminar en desarrollo**

- **Ampliación de vocabulario más reciente:** 24 entradas ilustradas incorporan 12 términos de medicina y 12 de ingeniería; también se renovaron las ilustraciones de enfermera y carga transportada. Consulta la [ampliación especializada más reciente](docs/specialist-expansion-7.md).
- **Ciencias en inglés:** _Water and Weather_ incorpora ocho lecciones ilustradas, 32 actividades de práctica, ocho tareas de escritura y 19 palabras nuevas de ciencias, con apoyo en persa, portugués y español.
- **Tres ediciones en una misma aplicación:** el estudio diario, el repaso espaciado, las lecturas, la práctica, la configuración y las copias de seguridad comparten la misma aplicación, con progreso independiente para cada edición.
- **Un atlas ilustrado en crecimiento:** el contenido actual reúne 402 palabras y 403 significados. Las 32 categorías tienen entradas ilustradas iniciales; cocina cuenta con 52 palabras, y medicina e ingeniería tienen 122 cada una. La etapa anterior de bases visuales añadió dos entradas por categoría, con estilos de ilustración adecuados a cada tema.

El contenido y las traducciones son una **versión preliminar editorial elaborada con ayuda de IA**, pendiente de revisión humana independiente. Los temas especializados también necesitan revisión de personas calificadas en la materia. Estas novedades describen el código y el contenido actuales del repositorio; la aplicación publicada corresponde al último despliegue manual. Consulta el [estado de implementación](docs/implementation-status.md) y el [registro de verificación](docs/verification.md) para conocer los detalles.

## Qué puedes hacer

| Área de aprendizaje             | Qué ofrece                                                                                                                                                                                                   |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Estudio diario                  | Define una meta diaria, aprende en pequeños grupos de palabras, practica la recuperación activa y repasa con el planificador de repetición espaciada FSRS.                                                   |
| Atlas ilustrado                 | Explora tarjetas con significados, ejemplos, colocaciones y pronunciación, además de búsqueda, filtros, palabras guardadas y una galaxia que muestra tu progreso.                                            |
| Lectura                         | Lee tres textos breves y un libro original de tres capítulos, con traducciones, preguntas de comprensión, marcadores y consulta de palabras dentro del texto.                                                |
| Práctica                        | Practica escritura de palabras, copia de oraciones, dictado, dos niveles de paráfrasis y tres grupos de palabras que suelen confundirse.                                                                     |
| Ciencias en inglés              | Describe observaciones, compara ideas y explica causas en _Water and Weather_, un curso introductorio dirigido aproximadamente a estudiantes de nivel A2 a comienzos de B1. Está en **Biblioteca → Cursos**. |
| Progreso y estudio sin conexión | Guarda tu progreso en el dispositivo, exporta o restaura una copia de seguridad e instala un paquete de estudio desde una compilación de producción para acceder sin conexión.                               |

El catálogo organiza **32 familias temáticas y 348 subcategorías**, desde la vida cotidiana y la cocina hasta la tecnología y la salud. Es un mapa de cobertura: muchas áreas todavía necesitan lecciones. Completar una lección de ciencias registra la participación en el curso por separado del dominio del vocabulario inglés; las tareas de escritura permiten guardar borradores y revisar tu propio trabajo.

### Tu progreso y tu dispositivo

El progreso, las palabras guardadas, las sesiones activas y el estado de las lecturas y los cursos se almacenan localmente y por separado para cada edición. No hay un servicio de cuentas ni sincronización automática entre dispositivos. Exporta una copia de seguridad antes de cambiar de dispositivo o borrar el almacenamiento del navegador.

Los paquetes sin conexión requieren una compilación de producción y espacio disponible en el navegador. Las voces en inglés del dispositivo permiten narrar textos y pronunciar palabras que no tienen grabaciones incluidas; su disponibilidad depende del navegador y del sistema operativo. Las herramientas de pago para generar contenido son utilidades opcionales para quienes mantienen el proyecto.

## Cómo contribuir

**Puedes ayudar sin escribir código.** Damos la bienvenida a docentes, estudiantes, traductores, ilustradores, especialistas que revisen contenido y desarrolladores.

| Tu interés                         | Una primera contribución útil                                                                                                            |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Idiomas y enseñanza                | Revisa cinco explicaciones o ejemplos de una lección; propone textos más claros en persa, portugués brasileño o español latinoamericano. |
| Aprendizaje y pruebas              | Prueba una lección en tu teléfono y reporta un paso confuso, un problema de diseño o una dificultad de accesibilidad.                    |
| Ilustración y temas especializados | Comprueba si una imagen comunica el significado que debe enseñar o revisa un módulo temático pequeño.                                    |
| Desarrollo y documentación         | Mejora un comportamiento concreto de la interfaz, corrige un error reproducible o aclara una instrucción de instalación.                 |

1. [Abre un issue](https://github.com/mehrdadxzaker/mehrdadika/issues/new/choose) para describir la corrección o la idea. Incluye la palabra o lección, el texto actual, tu propuesta y el motivo. Agrega identificadores de contenido, revisiones y referencias cuando los tengas; si no los encuentras, describe la pantalla y pide ayuda. Puedes escribir en persa, portugués, español o inglés.
2. Para cambiar código o contenido, lee [CONTRIBUTING.md](CONTRIBUTING.md) y la [guía de contenido](docs/contributing-content.md). Procura que tu pull request sea pequeño y fácil de revisar. Las guías detalladas de contribución están actualmente en inglés.
3. Registra con honestidad las fuentes, los permisos y el trabajo de revisión. La revisión independiente de idiomas y temas especializados es especialmente valiosa para que el contenido preliminar pueda avanzar hacia una publicación estable.

Sigue el [código de conducta](CODE_OF_CONDUCT.md). Para comunicar problemas de seguridad, consulta las instrucciones de [SECURITY.md](SECURITY.md).

## Ejecutar localmente

**Requisitos:** Node.js 22 o posterior, npm y Git. No se necesita un servidor de base de datos ni credenciales de IA.

```sh
git clone https://github.com/mehrdadxzaker/mehrdadika.git
cd mehrdadika
npm ci
npm run dev
```

Abre la dirección que aparece en la terminal, normalmente `http://127.0.0.1:5188`. El comando de desarrollo genera automáticamente las versiones de contenido y traducciones. Mantén un solo servidor de desarrollo o de vista previa activo a la vez.

### Verificar y compilar

```sh
npm test
npm run check:content
npm run campaign:status
npm run build
```

La salida de producción queda en `dist/`. Después de detener el servidor de desarrollo, ejecuta `npm run preview` para revisarla, incluidos los controles sin conexión de la versión de producción.

### Estructura del proyecto

```text
src/               Aplicación React + TypeScript, flujos de estudio e interfaz por idioma
content/           Vocabulario, lecturas, cursos, traducciones y procedencia
public/            Archivos estáticos y versiones de contenido generadas
scripts/           Generación de contenido, validación y pruebas de regresión
docs/              Guías de autoría, planes y registros de verificación
```

Edita las fuentes de autoría en `content/`; vuelve a generar el contenido publicado y las versiones de traducción con las herramientas documentadas. Conserva los identificadores de palabras y significados para que las correcciones respeten el progreso del estudiante.

## Despliegue

Publica `dist/` en un alojamiento estático. Para GitHub Pages bajo la ruta del repositorio:

```sh
ATLAS_BASE=/mehrdadika/ npm run build
```

Usa `ATLAS_BASE=/` para la raíz de un dominio. El repositorio incluye el flujo **Deploy GitHub Pages**, que se ejecuta manualmente; los envíos de cambios y los pull requests no despliegan la aplicación de forma automática. Conserva los archivos de las versiones de contenido al actualizar el sitio para que las sesiones guardadas puedan seguir cargando sus versiones.
