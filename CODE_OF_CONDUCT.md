# Community code of conduct

Help make this project welcoming to learners and contributors from different backgrounds, languages and levels of expertise. Be respectful, specific and constructive when discussing code, language, culture or professional terminology.

We expect contributors to:

- Critique work and claims without attacking people.
- Explain corrections with evidence and acknowledge uncertainty.
- Respect privacy, attribution and the limits of their expertise.
- Welcome beginners and make review feedback actionable.
- Avoid harassment, discriminatory remarks, threats, sexual harassment, doxxing and repeated unwanted contact.

Maintainers may edit or remove harmful material, limit a discussion or restrict participation when necessary to protect the community. They should explain the relevant behavior and apply decisions consistently. A disagreement about a translation or technical choice is not by itself misconduct.

Report concerns privately to a project maintainer. Do not publish another person’s private information in a conduct report. If a maintainer is involved, contact another available maintainer. Use the security reporting path for a vulnerability rather than exposing it in a public conduct discussion.
