# Mehrdadika · مهردادیکا

**Aprenda inglês com imagens, leituras e temas do dia a dia — com orientação no seu idioma.**

Mehrdadika é um aplicativo web gratuito e de código aberto para aprender inglês, voltado a falantes de persa, português brasileiro e espanhol latino-americano. Explore palavras ilustradas, crie um hábito diário de estudo e pratique inglês com histórias e ciências. Todas as edições ensinam inglês; as explicações e instruções acompanham você no idioma escolhido.

[Experimente o aplicativo](https://mehrdadxzaker.github.io/mehrdadika/#/pt-BR) · [Contribua](#como-contribuir) · [Relate um problema](https://github.com/mehrdadxzaker/mehrdadika/issues/new/choose)

## Novidades recentes

**30 de outubro de 2026 · Prévia em desenvolvimento**

- **Expansão de vocabulário mais recente:** 20 entradas ilustradas acrescentam 8 termos de medicina e 12 de engenharia. Veja a [expansão especializada mais recente](docs/specialist-expansion-39-ready-1.md).
- **Ciências em inglês:** _Water and Weather_ reúne oito lições ilustradas, 32 atividades de prática, oito propostas de escrita e 19 novas palavras de ciências, com apoio em persa, português e espanhol.
- **Três edições no mesmo aplicativo:** estudo diário, revisão espaçada, leitura, prática, configurações e backups compartilham a mesma aplicação, com progresso separado por edição.
- **Um atlas ilustrado em expansão:** o acervo atual tem 1154 palavras e 1155 sentidos. Todas as 32 categorias têm entradas ilustradas iniciais; culinária reúne 52 palavras, e medicina e engenharia têm 497 e 499, respectivamente. A etapa anterior de bases visuais acrescentou duas entradas por categoria, com estilos de ilustração adequados a cada tema.

O conteúdo e as traduções são uma **prévia editorial com apoio de IA**, ainda à espera de revisão humana independente. O material especializado também precisa de revisão por pessoas qualificadas na área. Estes destaques descrevem o código e o conteúdo atuais do repositório; o aplicativo publicado acompanha a última implantação manual. Consulte o [estado da implementação](docs/implementation-status.md) e o [registro de verificação](docs/verification.md) para mais detalhes.

## O que você pode fazer

| Área de estudo             | O que oferece                                                                                                                                                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Estudo diário              | Defina uma meta diária, aprenda em pequenos grupos de palavras, pratique a recordação ativa e revise com o agendador de repetição espaçada FSRS.                                                  |
| Atlas ilustrado            | Explore cartões com significados, exemplos, combinações frequentes de palavras e pronúncia, além de busca, filtros, palavras salvas e uma galáxia do seu progresso.                               |
| Leitura                    | Leia três textos curtos e um livro original de três capítulos, com traduções, perguntas de compreensão, marcadores e consulta de palavras durante a leitura.                                      |
| Prática                    | Experimente digitação de palavras, cópia de frases, ditado, dois níveis de paráfrase e três grupos de palavras que costumam causar confusão.                                                      |
| Ciências em inglês         | Descreva observações, compare ideias e explique causas em _Water and Weather_, um curso introdutório voltado aproximadamente aos níveis A2 e início do B1. Encontre-o em **Biblioteca → Cursos**. |
| Progresso e estudo offline | Salve o progresso no seu dispositivo, exporte ou restaure um backup e instale um pacote de estudo a partir da versão de produção para acesso offline.                                             |

O catálogo mapeia **32 áreas temáticas e 348 subcategorias**, da vida cotidiana e culinária à tecnologia e saúde. É um mapa de cobertura: muitas áreas ainda precisam de lições. Concluir uma lição de ciências registra a participação no curso separadamente do domínio do vocabulário em inglês; as atividades de escrita usam rascunhos salvos e autoavaliação.

### Seu progresso e dispositivo

O progresso, as palavras salvas, as sessões ativas e o estado das leituras e dos cursos ficam armazenados localmente, separados por edição de idioma. Não há serviço de contas nem sincronização automática entre dispositivos. Exporte um backup antes de trocar de dispositivo ou limpar o armazenamento do navegador.

Os pacotes offline exigem uma versão de produção e espaço disponível no navegador. As vozes em inglês do dispositivo permitem a narração e a pronúncia de palavras sem gravações incluídas; a disponibilidade depende do navegador e do sistema operacional. As ferramentas pagas de geração de conteúdo são recursos opcionais para quem mantém o projeto.

## Como contribuir

**Você pode ajudar sem escrever código.** Professores, estudantes, tradutores, ilustradores, revisores de áreas específicas e desenvolvedores são bem-vindos.

| Seu interesse                      | Uma primeira contribuição útil                                                                                                            |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Idiomas e ensino                   | Revise cinco explicações ou exemplos de uma lição; sugira textos mais claros em persa, português brasileiro ou espanhol latino-americano. |
| Aprendizagem e testes              | Experimente uma lição no celular e relate uma etapa confusa, um problema de layout ou uma barreira de acessibilidade.                     |
| Ilustração e áreas de conhecimento | Verifique se uma imagem ensina o significado pretendido ou revise um pequeno módulo temático.                                             |
| Desenvolvimento e documentação     | Melhore um comportamento específico da interface, corrija um erro reproduzível ou esclareça uma instrução de configuração.                |

1. [Abra uma issue](https://github.com/mehrdadxzaker/mehrdadika/issues/new/choose) descrevendo a correção ou ideia. Inclua a palavra ou lição, o texto atual, a proposta de alteração e o motivo. Acrescente os identificadores do conteúdo, as revisões e as referências quando disponíveis; se não conseguir encontrá-los, descreva a tela e peça ajuda. Aceitamos contribuições em persa, português, espanhol e inglês.
2. Para alterar código ou conteúdo, leia [CONTRIBUTING.md](CONTRIBUTING.md) e o [guia de conteúdo](docs/contributing-content.md). Mantenha seu pull request pequeno e fácil de revisar. Os guias detalhados de contribuição estão atualmente em inglês.
3. Registre fontes, permissões e revisões com honestidade. A revisão independente de idiomas e de áreas específicas é especialmente valiosa para levar o conteúdo de prévia a uma publicação estável.

Siga o [código de conduta](CODE_OF_CONDUCT.md). Para questões de segurança, use as instruções de relato em [SECURITY.md](SECURITY.md).

## Executar localmente

**Requisitos:** Node.js 22 ou mais recente, npm e Git. Não é necessário configurar um servidor de banco de dados nem fornecer credenciais de IA.

```sh
git clone https://github.com/mehrdadxzaker/mehrdadika.git
cd mehrdadika
npm ci
npm run dev
```

Abra o endereço exibido no terminal, normalmente `http://127.0.0.1:5188`. O comando de desenvolvimento gera automaticamente os arquivos de conteúdo e tradução usados pelo aplicativo. Mantenha apenas um servidor de desenvolvimento ou de pré-visualização ativo por vez.

### Verificar e gerar a versão de produção

```sh
npm test
npm run check:content
npm run campaign:status
npm run build
```

A saída de produção fica em `dist/`. Depois de parar o servidor de desenvolvimento, execute `npm run preview` para conferir a versão gerada, incluindo os controles offline de produção.

### Estrutura do projeto

```text
src/               Aplicativo React + TypeScript, fluxos de estudo e interface por idioma
content/           Vocabulário, leituras, cursos, traduções e procedência dos materiais
public/            Arquivos estáticos e versões de conteúdo geradas e versionadas
scripts/           Geradores de conteúdo, validação e verificações de regressão
docs/              Guias de autoria, planos e registros de verificação
```

Edite os arquivos-fonte de autoria em `content/`; gere novamente o conteúdo publicado e os arquivos de tradução com as ferramentas documentadas. Preserve os identificadores das palavras e dos sentidos para que as correções mantenham o progresso de quem estuda.

## Implantação

Sirva `dist/` em uma hospedagem estática. Para o GitHub Pages no caminho do repositório:

```sh
ATLAS_BASE=/mehrdadika/ npm run build
```

Use `ATLAS_BASE=/` para hospedar na raiz de um domínio. O repositório inclui o fluxo **Deploy GitHub Pages**, acionado manualmente; pushes e pull requests não publicam o aplicativo de forma automática. Preserve os arquivos de conteúdo versionados ao atualizar o site, para que as sessões salvas ainda possam carregar suas versões.
